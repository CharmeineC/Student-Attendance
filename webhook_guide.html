Setting up the Messenger Webhook

This allows parents to message your Facebook Page with their child's RFID code and get automatically linked to receive notifications. Follow these steps once.

1
Download and install ngrok
ngrok creates a temporary public URL for your local server so Facebook can reach it.

Go to ngrok.com, sign up for free, download the Windows version, and extract it to your Desktop.
✅ ngrok is free and safe — it's used by millions of developers worldwide.
2
Start ngrok
Open Command Prompt and type:
cd %USERPROFILE%\Desktop
ngrok http 5000
You will see a screen with a URL like:
Forwarding: https://abc123.ngrok.io → http://localhost:5000
Copy that https://abc123.ngrok.io URL — you need it next.
⚠️ Keep this ngrok window open. The URL changes every time you restart ngrok.
3
Enter the webhook URL in Facebook
Go back to developers.facebook.com → Your App → Use Cases → Messenger API Settings → Configure Webhooks.

Fill in:
Callback URL: https://abc123.ngrok.io/webhook
Verify token: {{ verify_token }}
Click Verify and Save.
✅ If verification succeeds, Facebook will show a green checkmark.
4
Subscribe to messages
Still on the Messenger API Settings page, find your page CES Attendance and click Add Subscriptions.

Check the box for messages and click Save.
5
Test it!
On your phone, open Facebook Messenger and search for your page CES Attendance. Send a message with a student's RFID code, for example:
0004A3F1
You should receive an automatic reply linking you to that student. 🎉
✅ Once linked, that parent will automatically receive notifications every time their child scans.
6
For permanent setup (optional)
ngrok URLs change every time you restart. For a permanent setup, either use ngrok's paid plan (fixed URL) or ask your school's IT administrator to set up port forwarding on the school router.

For now, ngrok free is fine for testing and enrollment day setup.
