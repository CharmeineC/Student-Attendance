1. Upload photos
Two ways to match photos to students — use whichever's easier: rename each file to include the student's 12-digit LRN (e.g. "129509250161.jpg" — fastest, no extra software needed), or leave filenames as-is if the LRN is visibly printed/typed somewhere in the photo itself (e.g. on an ID card) — the system will try to read it automatically, but this requires OCR software installed on the host. Filenames are checked first; OCR is only used as a fallback for files without an LRN in the name.
